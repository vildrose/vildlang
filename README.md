# Vildlang

Vildlang is the frontend language for vildcode intermediate representation. This should mainly be seen as a research project trying to prove that radix-neutrality and heterogeneous compute, have a place in a modern style language.

The end goal with Vildlang, is to prove that these concepts work, and can make sense, especially as we progress into a world of more differing compute platforms, both as more code needs to run GPUs, NPUs, and future hardware platforms (maybe also some older "historic" hardware).
